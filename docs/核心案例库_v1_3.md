记录的是:为什么资金会选择它。

二、驱动结构定义
驱动结构本质智能套利产业价值重估本能复制市场条件反射双结构共振产业逻辑 + 资金记忆叠加
智能套利三槽

规律:规律拥有者方向(Huang / Musk / Hassabis / Altman)
巨头产业进展:规律拥有者或其核心节点公司的动作

规律拥有者直接动作 ✓
核心节点公司动作(NVDA / 康宁 / Tesla 等) ✓
海外细分龙头动作(Sitime / Broadcom 等)= 巨头进展的产业链映射,算巨头进展 ✓
政策驱动事件 = 巨头进展的远端反射,不算巨头进展 ✗


国内映射方向:有真实供应链承接路径

双结构共振判定
必须同时满足:

国内映射方向上智能套利成立(三槽全部成立)
标的在该方向上有资金记忆
同一标的同时承担两个角色

重要边界:资金记忆必须是当前方向上的历史绑定,妖性不能跨方向迁移。

历史在 A 方向是妖股,公司进入 B 方向 ≠ B 方向有资金记忆
案例:京东方 A 历史是面板妖股,但 AI 玻璃基封装是新方向,不算共振

案例库的功能边界

回答:是不是机会 + 标的池是谁
不回答:何时入场 / 何时退出 / 持有多久(节奏判断属于实操层)
